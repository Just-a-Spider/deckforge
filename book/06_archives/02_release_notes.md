# Release Notes & Changelog

## v1.1.0-dev (In Progress)
- **Living Development Book**: Repository-backed codex in `book/` tracking vision, milestones, ADRs, and achievements.
- **DeckForge Studio Architecture**: Blueprint for hybrid TUI + 1080p Canvas Studio.
- **Angular-Inspired Component Schema**: Formal declarative specification with inputs and slots.
- **Intelligent Tokens Engine**: Automated WCAG 2.1 contrast validator with Recommended Actions.
- **First-Class AI Layer**: Native MCP server and headless JSON CLI subcommands for Claude Code, Gemini, Antigravity, and OpenClaw.

- 100% pure Go binary with embedded assets.
- Deterministic 1920x1080 stage scaling.
- Bubble Tea TUI with Decks, Slides, Scaffold, Themes, and Settings views.
- 14 curated skill presets.
- 4K slide capture and live file watching via fsnotify.
