Gamepad controls cannot tolerate TCP head-of-line blocking or Nagle delays. SysMon transmits raw, packed 28-byte UDP datagrams with monotonic sequencing:

OFFSETFIELDDESCRIPTION
00..04magic[4]ASCII "3PAD" (0x33, 0x50, 0x41, 0x44)
04..08sequ32 Monotonic sequence number (anti-replay)
08..12pinu32 Numeric authorization key validation
12..16buttonsu32 Bitmask: ABXY, D-Pad, L/R, ZL/ZR, Select/Start
16..20circle_x/ys16 Circle Pad analog axes (-156 to +156)
20..24right_x/ys16 C-Stick / Touch Screen virtual stick
24..28flagsu32 Operational flags and packet modifiers
Emergency Grab Release: Holding the top-right touch digitizer corner for 1.5 seconds instantly disengages controller lock and releases input capture.
KERNEL INTEGRATION
Rootless /dev/uinput Driver
LINUX EVDEV

The Rust daemon uses the evdev crate to register a genuine hardware gamepad in the Linux kernel without requiring root privileges:

# 99-sysmon-uinput.rules (udev)
KERNEL=="uinput", SUBSYSTEM=="misc", TAG+="uaccess", OPTIONS+="static_node=uinput"
# User added to group: sudo usermod -aG input $USER
Universal Gamepad Emulation: Creates standard virtual joydev (/dev/input/jsX) recognized out-of-the-box by Steam, RetroArch, PCSX2, and SDL2 titles.
Zero Polling Overhead: Events are emitted directly via kernel ioctl calls only on actual state delta changes, maintaining zero idle CPU wakeups.
