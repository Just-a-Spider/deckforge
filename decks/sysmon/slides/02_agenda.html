TIERED SUBSYSTEM TOPOLOGY
Tri-Component Architecture
RUST + C99 + WEB
1. HOST DAEMON (sysmon-server):

Headless Rust background daemon residing in the Linux system tray. Continuously polls hardware sensors (/sys/class/hwmon), mediates MPRIS D-Bus player controls, and drives kernel /dev/uinput.

2. HANDHELD CLIENT (sysmon-3ds):

Native Nintendo 3DS homebrew application authored in C99 using devkitARM and libctru. Renders 20 FPS telemetry via PICA200 GPU (citro2d) and captures Circle Pad / touch inputs.

3. EMBEDDED DASHBOARD (sysmon-web):

Lightweight HTTP micro-server embedded on port 7342. Provides a secured localhost config console for PIN and macro assignments, alongside a responsive mobile telemetry HUD.

Zero Cloud Footprint: 100% self-hosted peer-to-peer Wi-Fi communication with zero external telemetric dependencies or cloud telemetry leakage.
