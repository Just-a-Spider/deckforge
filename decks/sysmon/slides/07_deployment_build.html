Linux Host Daemon (Rust)
CARGO & PACKAGING

The Linux background daemon is compiled with Cargo using Rust 2024 edition. Multiple distribution workflows are supported:

OPTION A: NATIVE RPM (Fedora / RHEL / openSUSE):
cd sysmon-server && cargo build --release
cargo generate-rpm
sudo rpm -i target/generate-rpm/sysmon-server-*.rpm
OPTION B: ARCH LINUX / CACHYOS / MANJARO:
./install-arch.sh
# Or compile PKGBUILD directly: cd sysmon-server/packaging && makepkg -si
Automated udev Permissions:

Pre-packaged releases install 99-sysmon-uinput.rules and grant rootless gamepad access automatically.
