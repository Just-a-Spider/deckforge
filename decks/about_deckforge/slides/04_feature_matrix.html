Relative Luminance Formula (WCAG 2.1)
ISO/IEC 40500

Relative luminance $L$ measures perceived brightness for sRGB channels normalized to $[0, 1]$ and converted to linear space:

C_linear = (C_srgb ≤ 0.04045) ? C_srgb / 12.92 : ((C_srgb + 0.055) / 1.055)^2.4
L = 0.2126 * R_lin + 0.7152 * G_lin + 0.0722 * B_lin
Contrast Ratio = (L_lighter + 0.05) / (L_darker + 0.05)
