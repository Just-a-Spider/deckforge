Criptografía Autenticada: AES-256-GCM
AEAD • CONFIDENCIALIDAD + INTEGRIDAD CRIPTOGRÁFICA
NIVEL MAESTRO
01. PARÁMETROS DEL CIFRADOR:

Clave simétrica de 256 bits, vector de inicialización (Nonce/IV) de 96 bits generado mediante CSPRNG (os.urandom(12)) y Auth Tag de 128 bits (GHASH) para validar autenticidad.

RIESGO CRÍTICO: REUTILIZACIÓN DE NONCE:
Repetir un Nonce bajo la misma clave destruye la autenticidad en GCM, permitiendo recuperar la subclave hash y falsificar mensajes. Cada registro exige un Nonce único.
02. AAD (ADDITIONAL AUTHENTICATED DATA):

Permite ligar metadatos en claro (e.g. user_uuid, tenant_id) al tag criptográfico sin cifrarlos. Impide ataques de transplante de ciphertext entre tablas o cuentas de distintos usuarios.

Criterio de Examen: En peritajes forenses, el uso de modo ECB o CBC sin HMAC tipifica negligencia inexcusable ante la ANPD.
Arquitectura Envelope Encryption
SEGREGACIÓN ESTRICTA: DEK (LOCAL) VS. KEK (HSM/KMS)
ZERO TRUST
01. DATA ENCRYPTION KEY (DEK):

Clave simétrica efímera de un solo uso generada para cifrar el registro de base de datos. Solo reside en la memoria RAM de la aplicación durante los microsegundos que dura la mutación.

02. KEY ENCRYPTION KEY (KEK / MASTER KEY):

Clave raíz custodiada exclusivamente dentro de un módulo HSM físico certificado FIPS 140-3 Level 3 o Cloud KMS (AWS KMS, GCP Cloud Key Management, HashiCorp Vault).

WORKFLOW ENVELOPE EN DB:
Se almacena: [Encrypted_Data + Encrypted_DEK + Nonce + Tag]. Al terminar de cifrar, se ejecuta memory zeroization de la DEK en texto plano.
Criterio de Examen: La KEK maestra NUNCA se persiste en archivos .env, código fuente, variables de servidor ni dumps de BD.
HASHING DE CREDENCIALES: ARGON2ID
Función memory-hard resistente a ataques por fuerza bruta con GPUs y ASICs ($m=64\text{MB}, t=3, p=4$). Prohibido terminantemente MD5, SHA-1 o SHA-256 simple sin salt.
ROTACIÓN AUTOMÁTICA DE CLAVES (KMS)
Rotación anual de la KEK en el HSM. Permite descifrar DEKs antiguas sin reencriptar terabytes de datos en disco (re-wrapping síncrono únicamente de la clave de envoltura).
CUMPLIMIENTO DIRECTIVA R.D. 019-2013
Exigido de manera vinculante para Nivel Maestro (bancos de datos de salud, biometría de iris, huellas digitales y registros de antecedentes o solvencia patrimonial).
GLOSARIO CRIPTOGRÁFICO: AEAD: Authenticated Encryption with Associated Data AAD: Additional Authenticated Data DEK: Data Encryption Key (Clave local) KEK: Key Encryption Key (Clave maestra) KMS / HSM: Key Management Service / Hardware Security Module CSPRNG: Crypto-Secure Pseudo-Random Number Generator FIPS: Federal Information Processing Standards (NIST)
